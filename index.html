서비스 소개

비슷한 실력의 사용자와 알고리즘 문제로 대결하는 서비스입니다. 경쟁을 통해 주도적으로 학습하고, 승리에서 오는 성취감을 느낄 수 있습니다.

주요 기능

  • 비슷한 실력의 사용자끼리 실시간 매칭
  • 두 플레이어의 실력을 고려한 동일 문제 제공
  • 검증된 자체 문제은행에서 문제 출제
  • 실시간 경기 상태 확인
  • 승패에 따른 점수 및 티어 변화
  • 경기 기록 확인
  • 부정행위 방지

게임 진행 방법

  1. 비슷한 실력의 매칭 상대를 찾는다.
  2. 두 사용자에게 동일한 알고리즘 문제를 제공한다.
  3. 상대보다 먼저 정답을 제출한다.
  4. 경기 결과에 따라 점수와 티어가 변한다.

문제 제공 방식

AI를 활용해 문제 초안과 테스트 데이터를 만들고, 사전에 검증한 문제를 자체 문제은행에 저장합니다.
랭크전에서는 두 플레이어의 평균 레이팅을 기준으로 적절한 난이도의 문제를 자동으로 선택하고, 일반전에서는 사용자가 원하는 난이도를 직접 선택할 수도 있습니다.

건의사항



향후 추가하고 싶은 기능

  • 오답 및 시간·메모리 초과 페널티
  • 친선 대회
  • 실시간 경기 관전
  • 티어 최초 달성 이벤트
  • AI 문제 생성 및 검증 자동화 고도화

먼저 단순한 승리 판정을 구현한 후 세부 규칙과 추가 기능을 개발할 예정입니다.
