서비스 소개

비슷한 실력의 사용자와 알고리즘 문제로 대결하는 서비스입니다.
경쟁을 통해 주도적으로 학습하고, 승리에서 오는 성취감을 느낄 수 있습니다.

주요 기능

  • 비슷한 실력의 사용자끼리 실시간 매칭
  • 각 사용자의 실력을 고려한 동일 문제 제공
  • 실시간 경기 상태 확인
  • 승패에 따른 점수 및 티어 변화
  • 경기 기록 확인
  • 부정행위 방지

게임 진행 방법

  1. 비슷한 실력의 매칭 상대를 찾는다.
  2. 두 사용자가 동일한 알고리즘 문제를 확인한다.
  3. 상대보다 먼저 정답을 제출한다.
  4. 경기 결과에 따라 점수와 티어가 변한다.

온라인 저지 연동 방식

기존 온라인 저지에서 문제를 가져옵니다.
두 사용자에게 동일한 문제를 제공합니다.
초기 버전에서는 먼저 정답을 제출한 사용자를 승자로 처리합니다.
추후에는 오답이나 시간 초과 제출에 페널티를 적용할 예정입니다.
